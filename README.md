# tejaspattabhi.com

Personal website of Tejas Tovinkere Pattabhi, Staff Engineer working on cloud, distributed systems, and applied AI.

Live at **[tejaspattabhi.com](https://tejaspattabhi.com)**.

## Contents

- `index.html`: the whole site. A single static page with inline CSS and JavaScript, no framework or build step.
- `resume/`: résumé PDFs linked from the site.
  - `Tejas Pattabhi - Detailed CV.pdf`: two-page CV.
  - `one-page.pdf`: one-page résumé.
- `CNAME`: custom domain for GitHub Pages.

## Running locally

```sh
python3 -m http.server 8899
```

Then open http://localhost:8899.

## Deployment

Hosted on GitHub Pages from the `master` branch. Changes merged into `master` are published automatically.
